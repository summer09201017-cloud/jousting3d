操作

出手: 點畫面或空白鍵

蓄力大招: 長按出手 0.6 秒放開,發出刀光波動!

跳殺: 按 E(遠距飛身躍撲)｜飛殺: 按 R(近距閃電突進)

(衝刺一小段後按出手也能出:遠=跳殺、近=飛殺)

格擋: 按住 K / C / 舉盾鈕——正面擋箭無傷、擋刀減傷;剛舉盾瞬間被打=完美盾反!

前進 / 後退: W / S(↑ / ↓)

左轉 / 右轉: A / D(← / →)

自動面向: 敵人靠近自動轉身對準(A/D 或衝刺時不干預)

換武器: 1-8 直選,Q / Tab 循環,或點畫面下方武器條

衝刺(逃跑): 按住 Shift / 衝刺鈕——比對手快!
